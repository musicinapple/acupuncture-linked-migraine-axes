# Figure 1 (Workflow) generation

Figure 1 in `figures/final_figures/Fig1_Study_Workflow.jpeg` is generated reproducibly from a small Python script (matplotlib).

## Regenerate

```bash
python3 scripts/utils/make_fig1_workflow.py
```

Outputs:
- `figures/final_figures/Fig1_Study_Workflow.jpeg` (for the manuscript)
- `figures/final_figures/Fig1_Study_Workflow.png`
- `figures/final_figures/Fig1_Study_Workflow.pdf`
- `figures/final_figures/Fig1_Study_Workflow.svg`
